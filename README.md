# The Little Mermaid Jr — Digital Program

**St Mary Star of the Sea College · 21–23 May 2026**

An interactive digital flipbook of the production program, built as a static HTML site with animated page-turn effects. No frameworks or build tools required.

## 🌊 Live Site

Hosted via GitHub Pages: `https://<your-username>.github.io/<repo-name>/`

## 📁 Structure

```
index.html        # The flipbook (single self-contained file)
pages/            # PDF pages exported as JPGs (page_01.jpg … page_16.jpg)
README.md
```

## 🚀 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch → main → / (root)**
4. Save — your live link will appear within a minute

## 🎭 Features

- Animated 3D page-turn effect
- Click either side of the book or use **← →** arrow keys to navigate
- Thumbnail strip to jump to any spread
- Cover page displayed solo (right side only), as per print convention
- Underwater ocean aesthetic matching the production theme
- Fully responsive — works on desktop and mobile
